*artisan.txt* A wrapper around laravel's artisan command.

Author: Shubhanshu Tomar <tomarshubhanshu@protonmail.ch>

INTRODUCTION                                    *laravel-tools.nvim*

This plugin defines a single |Artisan| command which wraps the projects
artisan script. It automatically detects if valet is installed, if so the wrap
the command using `valet php artisan` instead of simply running `php artisan`.
This ensures that the correct php version is used if the project is using an
isolated php version using `valet isolate` (More information about Laravel
Valet at <https://laravel.com/framework/docs/13.x/valet>).

COMMANDS                                        *:Artisan*

:Artisan {args}

                           Runs an arbitrary artisan command in a split
                           terminal buffer. You can change the direction of
                           the split using |:command-modifiers|.


                                                *:Artisan_route:clist*
:Artisan route:clist [arg]

                           Fetches available routes using `artisan route:list`
                           and displays them inside a |quickfix| list.
                           Optionally takes an argument, and filters routes by
                           name as `artisan route:list --name=[arg]`.


                                                *:Artisan_route:cfind*
:Artisan route:cfind {arg}

                           Same as |:Artisan_route:clist| but {arg} is
                           required and uses |vim.ui.select()| instead of a
                           quickfix list.

                           If only one match was found the jumps to it
                           immediately.

                                                *:Artisan_route:ctags*
:Artisan route:ctags [arg]

                           Generate a tags file to navigate to routes, much
                           faster than |:Artisan_route:clist| or
                           |:Artisan_route:cfind| but you need to regenerate
                           tags every time you add a new route.

                           (Added this because forking to php everytime I need
                           to jump to a route was getting slow on my M1 work
                           mac).

                           If provided use [arg] as the filepath to write the
                           tags, otherwise use |g:laravel_tools_route_tags_file|
                           if provided. Fallsback to "./tags" relative to
                           |getcwd()|.

                           NOTE: This command replaces the contents of the
                           tags file.


                                                *:Artisan_tinker*
:[range]Artisan[!] tinker [args]

                           If no [args] are provided then create a new split
                           buffer (Split direction respects
                           |:command-modifiers|), where you can write any
                           php script. Evaluates the buffer on save.

                           If a treesitter parser for php is available then
                           uses it to wrap the last expression statement of
                           the script in a "dump();" call.

                           If a range is provided then evaluate code within
                           that range and show the output in a bottom split
                           (This does not respect |:command-modifiers|).
                           (Also note that this does require treesitter as of
                           now, I might conjure up some hack later).

                           If [args] and/or <bang> is provided then same as
                           |:Artisan|.


CONFIGURATION                                   *laravel-global-vars*

This plugin is configured using global variables.

                                                *g:laravel_tools_no_valet*

g:laravel_tools_no_valet        Set this variable to 1 if for some reason you
                                need to disable wrapping the command with `valet`.

                                                *g:laravel_tools_route_tags_file*

g:laravel_tools_route_tags_file Set this variable to the path fo tags file you
                                you want to write to.
